关于个人笔记

这是什么

个人笔记是一个本地运行的个人笔记应用，用 Markdown 写作，支持分享与评论。

功能一览

  • 注册与登录
  • Markdown 写作与实时预览
  • 草稿与发布
  • 划词 AI 润色
  • 笔记收藏
  • 链接分享（可设密码）
  • 评论互动

技术栈

  • 前端：HTML + CSS + 原生 JavaScript
  • 后端：Python + Flask
  • 数据库：SQLite
  • Markdown 渲染：marked.js（本地引入）
  • AI 润色：默认离线演示模式，可配置接入大模型服务

说明

本应用用于本地演示，不包含邮箱验证、找回密码、公开笔记广场等功能。AI 润色为演示模式时不会把文本发送到任何外部服务；启用真实服务后，被选中的文本会发送至你所配置的服务商。
